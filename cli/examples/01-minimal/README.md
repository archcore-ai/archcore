# 01 · minimal

> The smallest useful `.archcore/` — just a few documents.

A tiny project's context: an overview, the chosen stack, and one decision. Open
it with your agent and it can already answer questions about the project from
these three files.

**What's in `.archcore/` here**

- `architecture-overview.doc.md` — how the app is put together
- `tech-stack.rule.md` — the technologies this project sticks to
- `error-format.adr.md` — the decision on a single API error shape

## Try it

Install the CLI (see the [examples README](../README.md)), then open it with your agent —
**Claude Code:** `cd 01-minimal && claude` · **Cursor:** open the folder ·
**Codex CLI:** `cd 01-minimal && codex`.
