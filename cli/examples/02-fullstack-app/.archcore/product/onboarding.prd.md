## Problem

New users sign up but drop off before reaching first value. We need a guided
first-run that gets them to a created project within 3 minutes.

## Requirements

- Email + password and OAuth sign-up.
- A 3-step wizard: profile → invite teammates (optional) → create first project.
- Progress is resumable if the user leaves mid-flow.

## Out of scope

Billing and team roles — tracked in @.archcore/product/q3-roadmap.plan.md.
