## Problem

Collaboration is faked by sharing credentials. We need first-class shared spaces.

## Requirements

- A workspace owns projects; users join via invite.
- Roles for v1: owner and member only (finer permissions deferred).
- A user can belong to multiple workspaces and switch between them.

## Success

80% of active teams create a workspace within one month of launch. Rollout in
@.archcore/workspaces-rollout.plan.md; API in @.archcore/workspaces-api.spec.md.
