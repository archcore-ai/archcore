# 03 · product-planning

> Planning a feature, captured as living documents: a rough idea matured into a
> spec.

This is the "Team Workspaces" feature from first sketch to a draft spec — the idea, the
PRD it grew into, the rollout plan, and a still-draft API spec with open
questions. Handy for picking up where planning left off.

**What's in `.archcore/` here**

- `team-workspaces.idea.md` — the initial concept
- `team-workspaces.prd.md` — what we're actually building
- `workspaces-rollout.plan.md` — how we'll ship it
- `workspaces-api.spec.md` — the API contract (still a draft)

## Try it
