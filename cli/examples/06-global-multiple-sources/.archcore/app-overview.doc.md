## Overview

The customer-facing web application. It mounts three shared globals so the team
inherits company-wide standards without copying them:

- `company-standards` — backend / engineering baseline
- `design-system` — frontend standards and tokens
- `security-baseline` — secrets, auth, dependency policy

Local docs cover only app-specific choices (`frontend-stack.rule.md`).
