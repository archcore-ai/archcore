## Rule

This app is React + TypeScript + Vite, styled with the design-system tokens.
Routing is file-based; forms use one shared form library. Data fetching follows
the mounted design-system rule (React Query, object API) — not redefined here.

App-level choices live here; cross-company standards come from the globals.
